# Clean Blog template for DH101

Ready-to-edit HTML/CSS/JavaScript distribution of Clean Blog by Start Bootstrap.

- Selected article layout: https://startbootstrap.github.io/startbootstrap-clean-blog/post.html
- Original repository: https://github.com/StartBootstrap/startbootstrap-clean-blog
- License: MIT. Keep the included LICENSE and applicable copyright notices.

## Preview and edit

Download the repository ZIP, extract it, and open `templates/clean-blog/index.html` or `post.html` in your browser. No npm installation or build is required for these distribution files.

- `index.html`: blog-style homepage
- `post.html`: the sample article page selected by the team; duplicate it for research essays
- `about.html`: sample about page
- `contact.html`: sample contact page
- `css/styles.css`: compiled styling
- `js/scripts.js`: navigation scripts
- `assets/img/`: sample images

This is the original demonstration template, not completed HIV research. Replace the sample writing, author names, dates, navigation, image credits, and footer before presenting it as your project. Charts and an interactive timeline must be integrated separately.

The template loads Google Fonts, Font Awesome, and Bootstrap scripts from external services, so the full appearance and mobile navigation require internet access unless these dependencies are downloaded and linked locally. The contact form requires separate SB Forms configuration; it does not send messages automatically. Remove it if it is not needed.

## Repository and publishing

This template lives separately from `templates/editorial/` and `templates/rspress-site/`. It does not replace either template or change GitHub Pages settings. Your existing build may not publish this directory. Review the publishing workflow before choosing a template as the main website.

For advanced development using the upstream Pug/SCSS source, consult the original repository. Only the ready-to-use distribution and license are included here.

# Editorial template for DH101

Original Editorial HTML/CSS/JavaScript template by HTML5 UP.

- Original design and download: https://html5up.net/editorial
- Original live demo: https://html5up.net/uploads/demos/editorial/
- License: Creative Commons Attribution 3.0. See LICENSE.txt and https://html5up.net/license.

## Preview

Download the repository ZIP, extract it, open `templates/editorial`, and double-click `index.html` in a browser. No generator or package installation is required for this HTML template.

## Files

- `index.html`: sample homepage
- `generic.html`: sample content page
- `elements.html`: typography and interface examples
- `assets/css/main.css`: compiled styling
- `assets/sass/`: source styles, optional for basic HTML edits
- `assets/js/`: template scripts
- `images/`: sample visual assets

This directory contains the original demonstration content. It has not been rewritten as HIV research, and the demo text and images are not project evidence. Replace them with verified research, citations, and appropriately licensed media before presenting the project.

A possible project structure is Home, Timeline, Media, Research, and Team. Research charts and an interactive timeline must be added separately. The demo search and contact controls should be removed or implemented before publication.

## Publishing later

Adding this folder does not configure GitHub Pages. If your team later publishes the repository root using Pages, this template would be located under `/templates/editorial/` relative to that published root. An existing build process may publish a different folder and exclude this template.

To use Editorial as the main website, review the repository's actual publishing workflow first and integrate the files in a separate reviewed change. Do not overwrite another template or the root homepage without checking the team's work.

Keep the HTML5 UP design attribution and applicable license notices. Check image and font licenses separately.
